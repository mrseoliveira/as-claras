# Às Claras (nome provisório)

Jogo sobre discordar, ouvir e lidar com a raiva em conversas difíceis. Versão para estudantes universitários, em desenvolvimento.

- Jogo: `index.html`
- Curso de assertividade: `curso.html`
- Mapa das pontuações (todas as respostas, posturas e efeitos): `ferramentas/mapa-pontuacoes.html`

O jogo abre diretamente no browser, sem servidor. As respostas ficam guardadas só no browser de quem joga.
