# Às Claras (nome provisório)

Jogo sobre discordar, ouvir e lidar com a raiva em conversas difíceis. Versão para estudantes universitários, em desenvolvimento.

- Jogo: `index.html`
- Protótipo com a conversa em histórico, emoções no «E tu?» e registo anónimo das jogadas: `prototipo/index.html`
- Curso de assertividade: `curso.html`
- Mapa das pontuações (todas as respostas, posturas e efeitos): `ferramentas/mapa-pontuacoes.html`

O jogo abre diretamente no browser, sem servidor. No jogo principal, as respostas ficam guardadas só no browser de quem joga. No protótipo, o registo no Supabase só funciona com o projeto configurado em `prototipo/js/registo.js` e com consentimento de quem joga (tabela em `prototipo/ferramentas/supabase.sql`).
